## 파일 안내

- `tiles/base`, `tiles/transition`, `tiles/path`, `tiles/decal`: 개별 PNG.
- `manifest.json`: 논리 크기·앵커·지형 종류·경계/길 비트 명세.
- `catalog.csv`: 검색·정리용 파일 목록.
- `atlas.png`, `atlas.json`: 172개 파일을 묶은 아틀라스와 영역 좌표. 별도 원본이 아니라 동일 PNG 패킹본입니다.
- `maps/*.json`: 혼합 맵, 8개 지형쌍 예제, 길·수로 예제. 실제 미리보기 배치 그대로입니다.
- `previews`: 전체 조합·지형쌍별 조합·바탕/장식 목록·경계 목록·길 목록·확대본.
- `index.html`, `viewer.js`: 지형쌍 전환, 확대·축소, 격자·장식 토글, 역할/지형/파일명 필터. 이 폴더를 localhost로 제공해 열면 됩니다.
- `originals`: 승인 원본과 새 원본, 생성 프롬프트.
- `evidence`: 파일·연결 명세 검사 결과 및 검증 범위.

## 공통 아트 규칙

밝은 종이에 옅은 색, 필압이 바뀌는 검은 붓펜, 짧고 성긴 빗금, 넓은 여백을 유지합니다. 지형 내부의 점/획은 적게, 강한 선은 경계와 장식에 집중합니다. 물은 흰 물결, 돌밭은 작은 자갈획, 밀랍은 겹층, 재는 짧은 검댕획으로 구분합니다. 특수 의식 자국은 별도 데칼로 두어 모든 셀에 반복되지 않게 합니다.

초지 변형은 a 70% / b 20% / c 10%를 시작점으로 권장합니다. 좌표 해시로 선택해 재접속 시 지형이 바뀌지 않게 합니다. 장식은 일반 구역 12~30셀당 1개 정도로 시작하고 의식 흔적은 동선/거점에 한정합니다. 이는 시각 배치 제안이며 게임 규칙이 아닙니다.

## 크기와 배치

- 개별 PNG: 256×128 RGBA. 논리 표시 크기: 128×64 월드 픽셀.
- 투영: x=(i-j)×64, y=(i+j)×32. i는 오른쪽 아래, j는 왼쪽 아래.
- 앵커 (0.5, 0), 즉 이미지 상단 중앙이 셀의 위 꼭짓점입니다. 좌상단 그리기 방식이면 x-64, y에 128×64 크기로 배치합니다.
- 바탕을 먼저 그린 뒤 장식을 합성합니다. 장식은 이번 묶음에서 동일 캔버스와 앵커로 맞췄으며, 높이가 있는 장식의 정렬 기준은 셀의 중심입니다.
- 셀 바깥은 투명. 필터 틈 방지용 약 1px 연결 여유가 있어 실제 타일 셀 윤곽보다 조금 겹칩니다. 타일마다 검은 외곽선을 그리지 않습니다.
- 아틀라스는 3696×1768, 각 파일 사방 4px 투명 패딩, extrusion=0. 프레임 밖을 샘플링하지 않는 clamp 설정을 사용합니다. 게임의 Pixi/SpriteAtlas 패커로 다시 묶을 경우 자체 extrusion 규칙을 적용하고 검증해야 합니다.

## 지형 연결 규칙

지원 쌍: 초지↔흙, 초지↔돌밭, 흙↔돌밭, 초지↔습지, 습지↔물, 흙↔밀랍, 흙↔재, 재↔밀랍.

`A__B_*_mX`에서 A는 바탕, B는 확장 지형입니다. X는 16진수 꼭짓점 비트입니다. 비트 순서: 1=(u0,v0) 위, 2=(u1,v0) 오른쪽, 4=(u1,v1) 아래, 8=(u0,v1) 왼쪽. 해당 꼭짓점이 B이면 그 비트를 켭니다. m0은 A의 기본 타일, mf는 B의 기본 타일을 사용합니다. 나머지 m1~me는 모두 포함되어 있습니다.

m5/ma는 서로 떨어진 대각선 두 영역입니다. 연결 여부를 임의로 바꾸지 않고 분리 상태로 고정했습니다. 셀 꼭짓점은 이웃 셀과 같은 지형 값을 공유해야 합니다. 한 셀에 세 지형이 동시에 들어가는 경우는 지원하지 않습니다. 중간 지형을 최소 한 셀 이상 두고 이어야 합니다. 서로 직접 연결되지 않는 지형은 흙 또는 지원되는 중간 지형을 거칩니다.

## 길·수로 연결 규칙

`A__B_path_pX`: 비트 1=u0, 2=u1, 4=v0, 8=v1 방향으로 이어집니다. 화면 방향으로는 각각 왼쪽 위, 오른쪽 아래, 오른쪽 위, 왼쪽 아래입니다. 서로 맞닿는 두 셀은 반대 방향 비트를 함께 켭니다.

p0은 작은 고립 구역, 한 비트는 막힌 끝, 반대 두 비트는 직선, 인접 두 비트는 꺾임, 세 비트는 T자, pf는 십자입니다. 길 폭은 셀 축 기준 40%입니다. 이 길 세트는 같은 길 타일끼리 연결하는 용도이며, 넓은 지형 경계와의 전용 합류 타일은 포함하지 않습니다.

## 적용 범위

지형군의 이름은 시각 분류입니다. 현재 게임의 이동·충돌·피해·자원 규칙은 바꾸지 않았습니다. 신규 지형을 실제 게임의 `terrainMap`에 배정하는 작업도 하지 않았습니다. 기존 world.ts의 128×64, 120×120 격자에 맞는 시각 리소스입니다.

절벽·고도 측면은 현재 프로젝트가 평면 지형이므로 포함하지 않았습니다. 건설물, 캐릭터, 전체 리소스 교체도 이번 범위 밖입니다. 전체 맵 통합 전에 캐릭터 가독성·안개·아틀라스 필터·성능을 실제 Pixi 화면에서 확인해야 합니다.
